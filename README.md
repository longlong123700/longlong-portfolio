# Longlong · 游戏分析与攻略作品集

**[打开在线作品集 →](https://longlong-portfolio.mellow-robin-4864.chatgpt.site)**

围绕《梦境护卫队》的数值分析、资源规划和机制拆解，整理攻略文章与重点案例。

## 作品内容

- 活动套装强度与养成性价比分析
- 资源分配与投入产出评估
- PVE / PVP 机制拆解与策略建议
- 玩家需求洞察与版本反馈

## 本地运行

基于 React、TypeScript、Vite 和 Tailwind CSS。

```bash
npm ci
npm run dev
```

```bash
npm run build
```

构建产物位于 `dist/`。文章和分类在 `src/data/` 中维护。
